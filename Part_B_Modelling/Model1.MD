# Model 1 – Logistic Regression

## Purpose

Logistic Regression will be used as the first machine learning model to establish a baseline for predicting customer attrition.

It is an appropriate baseline model because it is relatively simple, interpretable, and commonly used for binary classification problems.

## Model Technique

The model used is **Logistic Regression**.

The target variable is:

* `Attrition_Flag`

The target is represented as:

* Existing Customer → 0
* Attrited Customer → 1

## Model Configuration

The following hyperparameter values will be used:

* `max_iter = 1000` – allows the model sufficient iterations to converge.
* `class_weight = "balanced"` – gives greater consideration to the minority class.
* `random_state = 42` – ensures reproducibility.

The model will therefore be configured as:

`LogisticRegression(max_iter=1000, class_weight="balanced", random_state=42)`

## Input Data

The model will use the feature-engineered dataset produced during the feature engineering stage.

The following types of information will be included:

* Customer demographic characteristics
* Account and relationship information
* Transaction behaviour
* Customer inactivity
* Engineered transaction features

Categorical variables will be converted into numerical variables using one-hot encoding.

Numerical variables will be standardised before being supplied to the Logistic Regression model.

## Model Training

The dataset will be divided into training and testing sets using a stratified 80/20 split.

The model will be trained using the training data and evaluated using the testing data.

## Evaluation Metrics

The following evaluation metrics will be used:

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC
* Confusion matrix

Particular attention will be given to recall and F1-score for the **Attrited Customer** class because identifying customers who may leave is important for the project.

## Related Code

The implementation of Logistic Regression will be provided in:

`model1.ipynb`

The notebook will contain the code for:

1. Loading the feature-engineered dataset
2. Preparing the target variable
3. Encoding categorical variables
4. Splitting the data
5. Scaling numerical features
6. Training the Logistic Regression model
7. Generating predictions
8. Evaluating model performance

## How to Use

The notebook should be run from beginning to end after the feature-engineering stage.

The input dataset should be the `feature_engineered.csv` file generated by `feature_engineering.ipynb`.

The notebook will produce the Logistic Regression model results and evaluation metrics.
