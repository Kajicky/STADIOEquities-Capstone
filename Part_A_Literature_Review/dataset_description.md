# Public Dataset – Credit Card Customers (BankChurners)

## Name

Credit Card Customers (BankChurners)

## Harvard Reference

Goyal, S. (n.d.) *Credit Card Customers*. Kaggle. Available at: https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers

## Link

https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers

## Number of Instances

10,127 customer records.

The dataset does not provide a predefined training and testing split. The researcher will create the training and testing partitions during Part B.

## Number of Feature Columns

The original dataset contains 23 columns in total. These include the customer identifier, target variable and two Naive Bayes classifier output columns. The identifier and the two Naive Bayes output columns will not be used as predictive features.

The remaining variables contain demographic, financial, account and behavioural information.

## Number of Classes

The dataset contains two classes:

- Existing Customer
- Attrited Customer

There are approximately 8,500 existing customers and 1,627 attrited customers.

## Target

The target variable is `Attrition_Flag`, which indicates whether a customer is an Existing Customer or an Attrited Customer.

This is therefore a classification problem.

## Origin

The dataset is publicly available through Kaggle and contains demographic, financial, credit-card and behavioural information about bank customers.

Variables include age, gender, education level, income category, card category, months on book, number of products, inactive months, transaction counts, transaction amounts, credit limit and credit utilisation.

## Reason for Selection

The dataset was selected because it was used in Peng, Peng and Li (2023), satisfying the assignment requirement that the public dataset must be used in one of the reviewed publications.

It is also relevant to the STADIOEquities problem because it contains customer demographic, financial and behavioural variables together with an attrition outcome. This provides a suitable public dataset for testing customer-disengagement prediction methods before applying similar methods to sensitive client data.
